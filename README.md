# ViralForge AI — MVP com IA real

## 1. Requisitos
- Node.js instalado
- Uma chave da OpenAI API

## 2. Configuração
Crie um arquivo chamado `.env` e coloque:
OPENAI_API_KEY=sua_chave

## 3. Instalação
npm install

## 4. Executar
npm start

Depois abra:
http://localhost:3000

IMPORTANTE:
Nunca coloque a chave da API dentro do HTML/JavaScript do navegador.
Ela fica somente no servidor.
